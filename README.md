One sentence, 184 characters, that explains the modern internet to a time traveler from 1800 — built only from what a person of 1800 already knows: a road, a letter, a town, a stranger, a page, a library. No word coined after their time, no list of features, just one picture with one twist: on this road, every reader may also write.

## Run it

```sh
node main.ts
```
